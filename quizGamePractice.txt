# 3. quiz.py 상세 (Quiz 클래스)

```text
quiz.py
└── class Quiz
    ├── 속성
    │   ├── question   # 문제 (문자열)
    │   ├── choices    # 선택지 4개 (리스트)
    │   ├── answer     # 정답 번호 1~4 (정수)
    │   └── hint       # 힌트 (문자열, 보너스)
    │
    └── 메서드
        ├── show()           # 문제 + 선택지 출력
        ├── check_answer(n)  # 입력 번호가 정답인지 True/False 반환
        ├── show_hint()      # 힌트 출력 (보너스)
        ├── to_dict()        # 저장용 → dict 변환 (JSON 저장 시)
        └── from_dict(d)     # 불러오기용 → dict에서 Quiz 생성 (classmethod)
```

### 역할 한 줄 정리
> `Quiz`는 **"퀴즈 1개가 스스로를 출력하고, 스스로 채점"** 하는 책임만 가집니다.  
> 게임 흐름/메뉴/저장은 전혀 몰라요. (책임 분리)

# 4. quiz_game.py 상세 (QuizGame 클래스 + 진입점)

```text
quiz_game.py
├── DEFAULT_QUIZZES          # 기본 퀴즈 5개 이상 (파일 없을 때 사용)
│
├── class QuizGame
│   ├── 속성
│   │   ├── quizzes          # Quiz 인스턴스 리스트

│   │   ├── best_record      # {correct, total} (예시 표시용)
│   │   └── history          # 게임 기록 리스트 (보너스)
│   │
│   └── 메서드
│       ├── run()              # 전체 루프 (메뉴 → 선택 → 기능 호출)
│       ├── show_menu()        # 메뉴 출력
│       ├── get_number_input() # 공통 숫자 입력/예외 처리 ★핵심
│       ├── get_text_input()   # 공통 문자열 입력/빈값 처리
│       ├── play_quiz()        # 퀴즈 풀기
│       ├── add_quiz()         # 퀴즈 추가
│       ├── show_quiz_list()   # 목록 보기
│       ├── show_score()       # 점수 확인
│       ├── delete_quiz()      # 퀴즈 삭제 (보너스)
│       ├── show_history()     # 기록 보기 (보너스)
│       ├── load_state()       # state.json 불러오기
│       └── save_state()       # state.json 저장
│
└── if __name__ == "__main__":   # 진입점
    └── QuizGame().run()
```

### 역할 한 줄 정리
> `QuizGame`은 **"메뉴를 보여주고, 사용자 입력을 받아 적절한 기능을 호출"** 하는 지휘자입니다.

# 6. 각 기능의 내부 연결

## 6-1. 퀴즈 풀기 (play_quiz)

```text
play_quiz()
   │
   ├─ quizzes 비었나? → "퀴즈 없음" 안내 후 복귀
   │
   ├─ random.shuffle()        (보너스: 랜덤 출제)
   ├─ get_number_input()      (몇 문제 풀지 선택 - 보너스)
   │
   └─ 각 문제마다 반복:
        ├─ Quiz.show()           ← quiz.py
        ├─ Quiz.show_hint()      ← quiz.py (힌트 요청 시, 보너스)
        ├─ get_number_input()    (정답 입력 1~4)
        └─ Quiz.check_answer()   ← quiz.py (채점)
   │
   ▼
결과 집계 → best_score 비교/갱신
   │
   ├─ history에 기록 추가 (보너스)
   └─ save_state() ──→ state.json 쓰기
```

## 6-2. 퀴즈 추가 (add_quiz)

```text
add_quiz()
   │
   ├─ get_text_input()      (문제 입력)
   ├─ get_text_input() × 4  (선택지 입력)
   ├─ get_number_input()    (정답 번호 1~4)
   │
   ├─ Quiz(...) 생성        ← quiz.py
   ├─ quizzes에 추가
   └─ save_state() ──→ state.json 쓰기
```

## 6-3. 목록 / 점수 / 삭제 / 기록

```text
show_quiz_list()
   ├─ quizzes 비었나? → 안내
   └─ 번호 + question 출력

show_score()
   ├─ 기록 없나? → "아직 풀지 않음" 안내
   └─ best_score + best_record 출력 (예: 80점 5문제 중 4문제)

delete_quiz()                 (보너스)
   ├─ show_quiz_list()로 목록 표시
   ├─ get_number_input()로 삭제 번호 선택

   └─ save_state() ──→ state.json 쓰기

show_history()                (보너스)
   └─ history 출력 (날짜/문제수/점수)

# 11. quiz.py

class Quiz:
    """농구 퀴즈를 표현하는 클래스"""
    
    def __init__(self, question, choices, answer, hint=""):
        """
        question (str): 퀴즈 문제
        choices (list): 4개의 선택지
        answer (int): 정답 번호 (1~4, JSON에서는 0~3 인덱스)
        hint (str): 힌트 (선택사항)
        """
        self.question = question
        self.choices = choices
        self.answer = answer  # JSON에서는 0~3 인덱스
        self.hint = hint
    
    def show(self):
        """문제와 선택지를 출력"""
        print(f"\n{self.question}")
        for i, choice in enumerate(self.choices, 1):  # 화면에는 1~4로 표시
            print(f"{i}) {choice}")
    
    def check_answer(self, n):
        """
        입력 번호가 정답인지 확인
        n (int): 사용자 입력 (1~4)
        return (bool): 정답 여부
        """
        return n == (self.answer + 1)  # JSON은 0~3, 사용자 입력은 1~4
    
    def show_hint(self):
        """힌트 출력"""
        if self.hint:
            print(f"💡 힌트: {self.hint}")
        else:
            print("💡 힌트가 없습니다.")
    
    def to_dict(self):
        """Quiz 객체를 dict로 변환 (JSON 저장용)"""
        return {
            "question": self.question,
            "choices": self.choices,
            "answer": self.answer,  # 0~3 인덱스로 저장
            "hint": self.hint
        }
    
    @classmethod
    def from_dict(cls, data):
        """dict에서 Quiz 객체 생성 (JSON 불러오기용)"""
        return cls(
            question=data["question"],
            choices=data["choices"],
            answer=data["answer"],  # 0~3 인덱스
            hint=data.get("hint", "")
        )

```
