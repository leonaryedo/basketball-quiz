# E1-2 컴퓨터에게 명령 내리는 말(파이썬) 처음 배우기

## 1. 프로젝트 개요

#### 동작하는 퀴즈 게임 만들기

- 프로그램 실행 시 메뉴에서 번호를 선택하면, 선택 결과에 따라 퀴즈 풀기/퀴즈 추가/퀴즈 목록/점수 확인/종료 화면이 출력된다.

- 퀴즈 풀기, 퀴즈 추가, 퀴즈 목록, 점수 확인, 종료 기능이 동작한다.

- 본인이 선택한 주제의 퀴즈가 5개 이상 포함되어 있다.

- 프로그램을 종료하고 다시 실행해도 추가한 퀴즈와 최고 점수가 유지된다.(파일 저장)

## 2. 퀴즈 주제 선정 이유

- 농구를 좋아하기 때문에 농구를 퀴즈 주제로 선택했습니다.

- 관심 있는 분야의 퀴즈를 만들면 더 재미있게 개발할 수 있고, 농구에 대해 이미 알고 있는 지식을 활용해서 퀴즈 문제를 쉽게 만들 수 있습니다.

## 3. 실행 방법 (예: python main.py)

#### GitHub에서 프로그램 가져와서 실행하기

- 1단계: 저장소 클론 (처음 가져올 때)
```
git clone https://github.com/your-username/quiz-game.git     #git clone - GitHub 저장소를 로컬에 복사합니다.
```

- 2단계: 프로그램 실행
```
cd quiz-game
python quiz_game.py     #리눅스 환경인 경우에 python3 quiz_game.py
```

실행결과(⚠️나중에 사진 추가)

=== 농구 퀴즈 게임 ===
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 최고 점수 확인
5. 종료

선택: 
메뉴가 나타나면 숫자를 입력하여 기능을 선택합니다.

- 3단계: 메뉴 사용 예시(⚠️나중에 사진 추가)
  
선택: 1          # 퀴즈 풀기 선택
문제 1/5: 농구에서 한 팀의 선수는 몇 명인가?
1) 4명
2) 5명
3) 6명
4) 7명

정답: 2          # 정답 입력
정답입니다! ✓

- 4단계: 저장소에 새로운 변경사항 가져오기 (이후 업데이트 시)
```
git pull     #원격 저장소의 최신 변경사항을 로컬에 가져옵니다.
```

## 4. 기능 목록(퀴즈 풀기/추가/목록/점수/종료)

| 번호 | 기능 | 설명 |
|:---:|:---:|:---|
|  1  | **퀴즈 풀기** | 저장된 농구 퀴즈를 순서대로 풀고 정답 입력 시 즉시 결과 확인. 모든 문제 완료 후 최종 점수 표시 |
|  2  | **퀴즈 추가** | 새로운 농구 퀴즈 추가. 문제, 4개 선택지, 정답 번호 입력 후 저장 |
|  3  | **퀴즈 목록** | 저장된 모든 퀴즈 확인. 각 퀴즈의 문제와 선택지 조회 |
|  4  | **최고 점수 확인** | 지금까지의 최고 점수 확인. 퀴즈 풀 때마다 자동 갱신 |
|  5  | **종료** | 프로그램 안전 종료. 모든 데이터 자동 저장 |
