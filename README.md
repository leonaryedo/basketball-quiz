# E1-2 🎯 농구 퀴즈 게임 [컴퓨터에게 명령 내리는 말(파이썬) 처음 배우기]

## 1. 프로젝트 개요

#### 동작하는 퀴즈 게임 만들기

- 프로그램 실행 시 메뉴에서 번호를 선택하면, 퀴즈 풀기/퀴즈 추가/퀴즈 목록/점수 확인/퀴즈 삭제/점수 기록/종료 화면이 출력된다.

- 본인이 선택한 주제의 퀴즈가 5개 이상 포함되어 있다.

- 프로그램을 종료하고 다시 실행해도 추가한 퀴즈와 최고 점수가 유지된다.(파일 저장)

- 농구를 좋아하기 때문에 농구를 퀴즈 주제로 선택했습니다.

- 관심 있는 분야의 퀴즈를 만들면 더 재미있게 개발할 수 있고, 농구에 대해 이미 알고 있는 지식을 활용해서 퀴즈 문제를 쉽게 만들 수 있습니다.

## 1. 파이썬 기초

#### 1) 변수가 무엇이고, 왜 사용하는가?

  - 변수란: 컴퓨터의 메모리에 저장하는 상자로 값을 담아둔다.
    
  - 왜 사용하는가?
    - 값을 기억하고 재사용하기 위해서 (재사용성): 컴퓨터는 계산을 하고 나면 결과를 금방 잊어버립니다. 계산한 결과나 중요한 데이터를 메모리에 저장(기억)해 두고, 필요할 때마다 몇 번이고 다시 불러다 쓰기 위해 변수가 필요합니다.
    - 코드의 가독성을 높이기 위해서 (가독성): 코드 안에 의미를 알 수 없는 숫자나 문자(예: 3.141592, 1000000)가 그대로 적혀 있으면 나중에 코드를 읽거나 수정할 때 무슨 뜻인지 알기 어렵습니다. 변수에 의미 있는 이름을 붙여주면 코드가 어떤 일을 하는지 한눈에 알아보기 쉬워집니다.
    - 값이 바뀔 때 쉽게 관리하기 위해서 (유지보수): 프로그램을 만들다 보면 데이터가 계속 바뀝니다. 예를 들어 게임에서 유저의 점수나 레벨, 쇼핑몰 장바구니의 총 금액 등은 수시로 변합니다. 변수를 사용하면 값 자체를 하드코딩(고정)하지 않고, 변수 안의 내용물만 쏙 바꿔 끼울 수 있어 프로그램 수정이 매우 편리해집니다.
    - 프로그램에 '동작'을 주기 위해서 (동적 처리): 프로그램은 사용자 입력이나 상황에 따라 결과가 달라져야 합니다. 예를 들어 사용자가 입력한 나이에 따라 다른 메시지를 출력하거나, 쇼핑몰에서 장바구니에 담는 물건에 따라 총합이 계산되려면 데이터를 담고 바꿀 수 있는 그릇(변수)이 필수적입니다.

#### 2) 기본적인 자료

| 데이터 타입 | 이름 | 설명 | 예시 |
| :---: | :--- | :--- | :--- |

| **`str`** | 문자열 | 작은따옴표(`''`)나 큰따옴표(`""`)로 감싼 텍스트입니다. | `"Hello"`, `'파이썬'` |

#### 3) 조건문

| 키워드 | 역할 및 설명 | 필수 여부 | 코드 예시 |
| :---: | :--- | :---: | :--- |
| **`if`** | 가장 먼저 실행되는 **최초의 조건**을 검사합니다. 참이면 해당 블록을 실행합니다. | **필수** | `if score >= 90:` |
| **`elif`** | 앞선 조건들이 모두 거짓이고, **새로운 조건이 참인지** 검사합니다. (여러 개 사용 가능) | 선택 | `elif score >= 80:` |
| **`else`** | 위의 **모든 조건이 거짓일 때** 무조건 실행되는 마지막 블록입니다. | 선택 | `else:` |

```python
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "F"

print(f"당신의 학점은 {grade}입니다.")  # 출력 결과: 당신의 학점은 B입니다.
```

#### 4) 반복문

| 구분 | `for`문 | `while`문 |
| :---: | :--- | :--- |
| **주요 목적** | **횟수**가 정해져 있거나, 데이터의 **처음부터 끝까지 순회**할 때 | 특정 **조건이 참(True)인 동안** 계속 반복할 때 |
| **반복 종료 시점** | 순회할 데이터나 범위가 끝났을 때 | 조건식의 결과가 거짓(False)이 되었을 때 |
| **주 사용 사례** | 리스트 요소 하나씩 꺼내기, 정해진 횟수만큼 반복 | 특정 상태가 될 때까지(예: 사용자 입력 대기, 게임 루프) |

```python
# 0부터 4까지 총 5번 반복
for i in range(5):
    print(f"현재 숫자: {i}")

# 리스트 요소 순회
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

# 카운트가 0보다 큰 동안 반복
count = 3
while count > 0:
    print(f"남은 시간: {count}")
    count -= 1  # 조건을 끝내기 위한 장치 필수!

print("발사!")
```

#### 5) 함수, 매개변수, 반환값

| 개념 / 용어 | 역할 및 설명 | 코드 예시 |
| :---: | :--- | :--- |
| **함수 정의 (`def`)** | 새로운 함수를 만들 때 사용하는 키워드입니다. 콜론(`:`)과 들여쓰기가 필수입니다. | `def add(a, b):` |
| **매개변수 (Parameter)** | 함수가 실행될 때 외부에서 **값을 전달받는 변수(입구)**입니다. | `def greet(name):` 의 `name` |
| **반환값 (`return`)** | 함수의 실행 결과를 함수 바깥으로 **내보내는 값(출구)**입니다. | `return result` |

```python
# 1. 함수 정의 (매개변수 a, b를 받아 더한 뒤 반환)
def add_numbers(a, b):
    result = a + b
    return result  # 반환값, return이 되면 함수는 종료

# 2. 함수 호출 (인수 3과 5를 전달)
sum_result = add_numbers(3, 5)  # 매개변수는 변수, 인는 그 값임

print(f"더하기 결과: {sum_result}")  # 출력 결과: 더하기 결과: 8
```

## 2. 클래스와 객체

#### 1) 클래스가 무엇이고, 왜 사용하는가?

  - 클래스란?: **"객체를 만들어내기 위한 설계도(Blueprint)"**입니다. 연관된 데이터(변수)와 기능(함수)들을 하나로 묶어서 관리할 수 있게 해주는 객체지향 프로그래밍(OOP) 도구입니다.
  
  - 왜 사용하는가?:
    - 데이터와 기능을 하나로 묶기 위해 (캡슐화): 관련된 변수들과 함수들이 여기저기 흩어져 있으면 코드가 복잡해집니다. 클래스를 쓰면 관련된 데이터와 기능을 하나의 상자(객체) 안에 깔끔하게 모아둘 수 있습니다.
    - 비슷한 구조의 객체를 대량으로 찍어내기 위해 (재사용성): 게임 캐릭터, 쇼핑몰 상품, 회원 정보처럼 구조는 같지만 데이터만 다른 객체가 수십, 수백 개 필요할 때 클래스라는 설계도 하나만 있으면 코드를 복사·붙여넣기 할 필요 없이 손쉽게 생성할 수 있습니다.
    - 코드의 유지보수와 확장성 향상: 프로그램 규모가 커져도 수정할 곳이 명확해집니다. 특정 기능이나 데이터를 수정할 때 해당 클래스 내부만 고치면 되므로 관리하기가 훨씬 수월해집니다.

| 개념 / 용어 | 역할 및 설명 | 코드 예시 |
| :---: | :--- | :--- |
| **클래스 (Class)** | 객체를 생성하기 위한 **설계도**(틀)입니다. | `class Car:` |
| **인스턴스 (Instance)** | 설계도를 바탕으로 실제로 만들어진 **구체적인 객체**입니다. | `my_car = Car()` |
| **생성자 (`__init__`)** | 인스턴스가 생성될 때 초기 속성(데이터)을 설정해주는 **특별한 함수**입니다. | `def __init__(self, name):` |
| **`self`** | 생성된 **인스턴스 자기 자신**을 가리키는 약속된 변수입니다. | `self.name = name` |

```python
# 1. 클래스 정의 (설계도)
class Car:
    # 생성자: 차를 만들 때 이름과 색상을 지정합니다.
    def __init__(self, name, color):
        self.name = name       # 속성 (데이터)
        self.color = color     # 속성 (데이터)
        self.speed = 0         # 기본 속도 (초기값)

    # 메서드 (함수/기능)
    def accelerate(self, value):
        self.speed += value
        print(f"{self.name}의 속도가 {self.speed}km/h로 증가했습니다.")

# 2. 인스턴스 생성 (설계도로 실제 차 만들기)
car1 = Car("소나타", "흰색")
car2 = Car("벤츠", "검은색")

# 3. 메서드 호출 (기능 사용)
car1.accelerate(30)  # 출력 결과: 소나타의 속도가 30km/h로 증가했습니다.
car2.accelerate(50)  # 출력 결과: 벤츠의 속도가 50km/h로 증가했습니다.
```
