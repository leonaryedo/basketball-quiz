# E1-2 🎯 농구 퀴즈 게임 [컴퓨터에게 명령 내리는 말(파이썬) 처음 배우기]

## 1. 프로젝트 개요

#### 동작하는 퀴즈 게임 만들기

- 프로그램 실행 시 메뉴에서 번호를 선택하면, 퀴즈 풀기/퀴즈 추가/퀴즈 목록/점수 확인/퀴즈 삭제/점수 기록/종료 화면이 출력된다.

- 퀴즈 풀기, 퀴즈 추가, 퀴즈 목록, 점수 확인, 퀴즈 삭제, 점수 기록, 종료 기능이 동작한다.

- 본인이 선택한 주제의 퀴즈가 5개 이상 포함되어 있다.

- 프로그램을 종료하고 다시 실행해도 추가한 퀴즈와 최고 점수가 유지된다.(파일 저장)

## 2. 퀴즈 주제 선정 이유

- 농구를 좋아하기 때문에 농구를 퀴즈 주제로 선택했습니다.

- 관심 있는 분야의 퀴즈를 만들면 더 재미있게 개발할 수 있고, 농구에 대해 이미 알고 있는 지식을 활용해서 퀴즈 문제를 쉽게 만들 수 있습니다.

## 3. 실행 방법

#### GitHub에서 프로그램 가져와서 실행하기

- 1단계: 저장소 클론 (처음 가져올 때)
```bash
git clone https://github.com/your-username/basketball-quiz.git
# git clone - GitHub 저장소를 로컬에 복사합니다.
```

- 2단계: 프로그램 실행

  - 메뉴가 나타나면 선택에 숫자(1~7)를 입력하여 기능을 선택합니다.(⚠️나중에 사진 추가)   
  ```bash
  cd basketball-quiz
  python quiz_game.py
  # 리눅스 환경인 경우에 python3 quiz_game.py
  ```
  
  ```
  ========================================
          🎯 농구 퀴즈 게임 🎯
  ========================================
  📂 저장된 데이터를 불러왔습니다. (퀴즈 5개, 최고점수 80점)
  ========================================
  1. 퀴즈 풀기
  2. 퀴즈 추가
  3. 퀴즈 목록
  4. 최고 점수 확인
  5. 퀴즈 삭제
  6. 점수 기록 보기
  7. 종료
  ========================================
  선택:
  ```

- 3단계: 메뉴 사용 예시(⚠️수정중 나중에 사진 추가)

  - 퀴즈 풀기
  ```
  선택: 1
  
  📝 퀴즈를 시작합니다! (총 5문제)
  
  ----------------------------------------

  1) 4명
  2) 5명
  3) 6명
  4) 7명

  ----------------------------------------

  ========================================
  🏆 결과: 5문제 중 4문제 정답! (80점)
  🎉 새로운 최고 점수입니다!
  ========================================
  ```
 
  - 퀴즈 추가
  ```
  선택: 2
  
  📌 새로운 퀴즈를 추가합니다.

  선택지 1: 20
  선택지 2: 21

  ```

  - 퀴즈 목록
  ```
  선택: 3
  
  📋 등록된 퀴즈 목록 (총 6개)
  
  ----------------------------------------
  ```

  - 최고 점수 확인
  ```

  ```

## 4. 기능 목록(퀴즈 풀기/추가/목록/점수/종료)

| 번호 | 기능 | 설명 |
|:---:|:---:|:---|
|  1  | **퀴즈 풀기** | 저장된 농구 퀴즈를 순서대로 풀고 정답 입력 시 즉시 결과 확인. 모든 문제 완료 후 최종 점수 표시 |
|  2  | **퀴즈 추가** | 새로운 농구 퀴즈 추가. 문제, 4개 선택지, 정답 번호 입력 후 저장 |
|  3  | **퀴즈 목록** | 저장된 모든 퀴즈 확인. 각 퀴즈의 문제와 선택지 조회 |
|  4  | **최고 점수 확인** | 지금까지의 최고 점수 확인. 퀴즈 풀 때마다 자동 갱신 |
|  5  | **퀴즈 삭제** | 등록된 퀴즈 중 불필요한 퀴즈 삭제. 번호 입력으로 선택 |
|  6  | **점수 기록 보기** | 게임 플레이 기록 조회. 날짜/시간/점수/정답률 확인 |
|  7  | **종료** | 프로그램 안전 종료. 모든 데이터 자동 저장 |

## 6. 데이터 파일 설명(state.json 경로/역할/필드 구조)

#### state.json 위치 및 역할

- 위치: 프로젝트 루트 (basketball-quiz/state.json)

- 역할: 퀴즈, 최고 점수, 게임 기록을 JSON 형식으로 저장

- 인코딩: UTF-8

- state.json 필드 구조
  ```bash
  {
      "quizzes": [
          {
              "question": "농구에서 한 팀의 선수는 몇 명인가?",
              "choices": ["4명", "5명", "6명", "7명"],
              "answer": 2,
              "hint": "NBA 경기에서 코트에 나가는 선수 수입니다."
          }
      ],
      "best_score": 80,
      "best_record": {
          "correct": 4,
          "total": 5
      },
      "history": [
          {
              "date": "2024-01-15 14:30:00",
              "correct": 4,
              "total": 5,
              "score": 80
          }
      ]
  }
  ```
  - 필드 설명
    
  | 필드 | 타입 | 설명 |
  |:---:|:---:|:---|
  | `quizzes` | 배열 | 등록된 모든 퀴즈 리스트 |
  | `quizzes[].question` | 문자열 | 퀴즈 문제 |
  | `quizzes[].choices` | 배열 | 4개의 선택지 |
  | `quizzes[].answer` | 정수 | 정답 번호 (1~4) |
  | `quizzes[].hint` | 문자열 | 힌트 (보너스) |
  | `best_score` | 정수 | 최고 점수 |
  | `best_record` | 객체 | 최고 점수 달성 시 정답/전체 문제 수 |
  | `best_record.correct` | 정수 | 최고 점수 달성 시 정답 수 |
  | `best_record.total` | 정수 | 최고 점수 달성 시 전체 문제 수 |
  | `history` | 배열 | 게임 플레이 기록 (최근 순서) |
  | `history[].date` | 문자열 | 플레이 날짜/시간 |
  | `history[].correct` | 정수 | 해당 게임의 정답 수 |
  | `history[].total` | 정수 | 해당 게임의 전체 문제 수 |
  | `history[].score` | 정수 | 해당 게임의 점수 |
